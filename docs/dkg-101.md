# DKG 101

OriginTrail DKG is a decentralized knowledge graph. For this starter app, think of it as structured memory for agents.

The app uses two Knowledge Asset shapes:

- Run Ledger: what happened during each attempt.
- Improvement Memory: what the agent should learn for the next attempt.

The starter app writes JSON-LD files in mock mode. A real DKG setup can use those JSON-LD/RDF files as Knowledge Asset payloads.

Memory layer mapping:

- Working Memory: private local iteration.
- Shared Working Memory: selected memory shared with peers.
- Verifiable Memory: final memory published with stronger durability and chain anchoring.

For hackathon Track 2, start with Working Memory. Use testnet Verifiable Memory when you want stronger submission evidence.
