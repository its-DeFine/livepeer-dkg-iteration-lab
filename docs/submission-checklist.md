# Submission Checklist

Before submitting a project based on this starter app, make sure you can show:

- What target your app tried to produce.
- Which Livepeer output references were created.
- What evaluation rubric was used.
- How the LLM judge scored the attempts.
- What the DKG Run Ledger stored.
- What the DKG Improvement Memory changed in the next attempt.
- Whether you used local Working Memory, Shared Working Memory, or Verifiable Memory.
- A link to the GitHub repo.
- A short demo video.

Do not submit secrets, private keys, private prompts, local paths, or private account details.
